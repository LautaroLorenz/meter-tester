# Reglas del proyecto

Una nota por regla. **Este README es el índice que lee el hook**
(`.claude/sync-vault-rules.sh`): solo se inyectan las reglas enlazadas acá con
`[[wikilinks]]`, en este orden. Agrupalas bajo encabezados `## `.

Una regla con `BLOQUEANTE` en el texto, o `⛔` / `⚠️` en el título, entra al `CLAUDE.md` con
su extracto; el resto entra como puntero.
